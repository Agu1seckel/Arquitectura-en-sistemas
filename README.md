# Web Institucional

Proyecto académico para una plataforma web institucional basada en el patrón arquitectónico Cliente-Servidor.

## Arquitectura

Usuario → Sistema Cliente → Servidor de Aplicaciones → Servidor de Base de Datos

## Tecnologías

- HTML
- CSS
- JavaScript
- Java + Spring Boot
- MySQL

## Estructura

- frontend/: interfaz web del sistema.
- backend/: servidor de aplicaciones y lógica del sistema.
- database/: scripts de base de datos.

El proyecto se desarrollará de forma incremental, manteniendo separadas la presentación, la lógica de negocio y el almacenamiento de datos.
